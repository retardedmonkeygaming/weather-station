First-Time Setup

Map your hardware pins and optionally connect Discord. Saved to .env — takes about a minute.

🖥️ LCD Pins (1602A · 4-bit mode · BCM numbering)

Each pin must be unique. Defaults match the classic wiring diagram.

🌡️ Sensors & Actuators

The DHT11 data line, the physical tap button, and the buzzer.

🤖 Discord Bot (optional but awesome)

Paste a bot token to enable /weather, /forecast, /setpage, /alarm-on//alarm-off, /set-alert, /status-embed, /liveupdate, and say “speak the weather” for a spoken summary. Admin commands respect the role below.

  1. Open the Discord Developer Portal → New Application
  2. Bot tab → Reset Token → copy it here
  3. OAuth2 → check bot + applications.commands → invite to your server

Channel ID: enable Developer Mode in Discord (Settings → Advanced), then right-click a channel → Copy Channel ID. Weather cards are posted there whenever data changes.

Stored only in your local .env — never synced or logged.

✅ Review & Save

The directory structure is created automatically. Pins take effect on next start.
